# ПОМЕХИ

Короткая визуальная новелла о ритме, слоях и дереализации. 6–8 минут, три концовки. Звук — брейккор — генерируется прямо в браузере через Web Audio, без аудиофайлов.

**Играть:** https://socdevvv.github.io/pomekhi/

## Управление

- Клик, `Space` или `Enter` — досказать строку / продолжить.
- Выборы — кнопками.
- `♪` — звук, `✦` — визуальные эффекты. Настройки и найденные концовки сохраняются в `localStorage`.
- На телефоне — тап по экрану.

## Концовки

Их три. Найденные отмечаются на титульном экране.

## Технически

- `index.html` — разметка.
- `styles.css` — оформление, зерно, сканлайны, глитч-эффекты.
- `game.js` — движок новеллы, сценарий, синтезатор брейккора.
- Внешних библиотек и шрифтов нет.
- Отладочный режим: `?debug=1` добавляет `window.__vn` (переходы по сценам, автопрохождение, проверка ссылок).

## Локальный запуск

Открыть `index.html` в браузере или поднять любой статический сервер в этой папке.
